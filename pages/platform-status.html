GitHub-native architecture

Platform Status

Central control-plane status without adding Supabase, Firebase, Cloudflare or another external platform.

External platforms: none

Available now

Main Engine runtimeBrowser registry, event bus and health summary.
Engine ManagerDedicated runtime registry page.
Local ActivityConsent-gated, session-local diagnostics only.
GitHub ActionsCan validate, build, deploy and maintain repository data using the repository's GitHub token.

Next server-side capabilities

Visitor AnalyticsRequires a GitHub-native ingestion mechanism; static browser code cannot securely write directly to GitHub APIs.
AccountsGitHub identity can be used for maintainer/admin access, but GitHub Pages alone is not an application authentication server.
History & AuditRepository-managed event records and Actions can provide auditable maintenance history.
Server-side controlsActions/workflows can perform controlled jobs; they are not a continuously running backend.

Important implementation rule

This project will not pretend that GitHub Pages is a conventional backend. Any feature requiring persistent visitor writes, real-time API endpoints or secure user sessions must have a concrete GitHub-native mechanism and explicit limitations before it is marked LIVE VERIFIED.
