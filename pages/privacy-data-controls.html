Privacy & Data Controls

Dedicated place for collection, consent, retention and deletion controls.

ACTIVE BOUNDARY

Current collection boundary

Local diagnostics are off by default. When enabled, only coarse page/interaction events are stored in session storage. The current Main Engine does not upload those events centrally.

Control principles

Collect only what the feature needs, keep analytics separate from logs, define retention before central storage, provide deletion controls where applicable, and never place privileged GitHub credentials in browser code.
